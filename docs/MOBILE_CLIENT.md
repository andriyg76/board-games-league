# Мобільний клієнт — Опис функціональності

## Загальна концепція

Мобільний клієнт для iOS (Swift) — це автономний застосунок для організації ігрових ліг настільних ігор. Він не потребує власного центрального сервера: всі дані зберігаються локально на пристрої, а синхронізація між учасниками виконується опціонально через зовнішній механізм. Автентифікація реалізована через Google OAuth безпосередньо, без Firebase.

---

## Аутентифікація

- Вхід через Google OAuth (Sign in with Google) нативно в iOS без Firebase
- Профіль гравця зберігається локально після першого входу
- Ім'я, аватар та псевдонім завантажуються з Google-акаунту і можуть бути змінені в застосунку
- Сесія зберігається локально; вихід з акаунту очищує локальні дані профілю

---

## Зберігання даних

- Основне сховище — локальна база даних на пристрої (SQLite через CoreData або GRDB)
- Всі ліги, гравці, типи ігор, ігрові раунди зберігаються на пристрої
- Опціональна синхронізація між пристроями учасників однієї ліги (наприклад, через iCloud або прямий P2P-механізм)
- Застосунок повністю функціонує офлайн; синхронізація відбувається при наявності зв'язку

---

## Ліги та рейтинги

### Управління лігами
- Створення нових ліг з назвою та налаштуваннями
- Перегляд списку ліг, в яких бере участь гравець
- Архівування завершених ліг
- Кожна ліга — ізольований контекст з власними учасниками, іграми та рейтингом

### Учасники ліги
- Статуси учасників: активний, очікує підтвердження, заблокований, віртуальний
- Управління учасниками: блокування / розблокування, зміна псевдоніму
- Створення віртуальних гравців (для гравців без акаунту)
- Відображення нещодавніх співгравців для швидкого вибору

### Таблиця лідерів
- Загальна таблиця очок по лізі
- Система нарахування очок:
  - Участь у грі: +2 очки
  - 1-е місце: +10, 2-е: +6, 3-є: +3, 4-е: +1
  - За 5-е місце і далі: `max(0, 11 − позиція)` очок
  - Модерування гри: +2 очки
- Статистика по кожному учаснику: кількість ігор, подіуми (1/2/3 місця), загальний рейтинг
- Сортування та фільтрація таблиці

---

## Запрошення гравців

- Генерація посилань-запрошень у лігу з терміном дії 7 днів
- Перегляд активних запрошень з можливістю продовжити або скасувати
- Прийняття запрошення за посиланням (deep link в iOS)
- Публічний перегляд інформації про запрошення без необхідності входу в акаунт
- Призначення псевдоніму гравцю через запрошення

---

## Типи ігор

### Вбудовані типи
- Класичне змагання (класичний підрахунок місць)
- Кооперативна гра (спільний результат команди)
- Командна гра (команда проти команди)
- Мафія (ролеві позиції)
- Wizard (спеціальний режим)

### Кастомні типи ігор
- Створення власних типів ігор з довільною назвою та іконкою
- Вибір типу підрахунку: класичний, кооперативний, командний, мафія, довільний
- Визначення ролей гравців (назва, мінімальна/максимальна кількість)
- Мінімальна та максимальна кількість гравців
- Локалізовані назви (українська, англійська)
- Захист вбудованих типів від видалення

---

## Ігрові раунди

### Створення гри
- Вибір типу гри та учасників ліги
- Призначення ролей (якщо тип гри передбачає ролі)
- Формування команд для командних ігор
- Вибір гравців зі списку нещодавніх співгравців

### Управління раундом
- Статуси раунду: вибір гравців → в процесі → підрахунок → завершено
- Введення очок та позицій для кожного гравця
- Підтримка кооперативних результатів (спільний рахунок)
- Підтримка командних результатів
- Фіналізація гри з автоматичним перерахунком рейтингу

### Перегляд ігор
- Список всіх ігор у лізі з фільтрацією за статусом
- Детальна інформація по кожній грі: склад, результати, дата

## Wizard — карткова гра

Спеціалізований режим для карткової гри Wizard з повним циклом управління партією.

### Налаштування гри
- Кількість гравців: 2–6 (визначає кількість раундів: 60 / кількість гравців)
- Варіант гри: стандартний або ювілейний
- Правило ставок: без обмежень / не можна повторити суму / потрібно повторити суму
- Вибір початкового дилера

### Процес гри
- Покрокове управління раундами (наступний / попередній / перезапуск)
- Фаза ставок: кожен гравець вводить свою ставку (кількість взяток)
- Фаза результатів: введення фактичних взяток
- Автоматичний підрахунок дельти по кожному раунду
- Перегляд поточних балів усіх гравців після кожного раунду
- Навігація між раундами для перегляду та редагування

### Завершення гри
- Фіналізація партії після останнього раунду
- Визначення переможця та розподіл місць
- Автоматичне збереження результатів в ігровий раунд ліги

## Інтерфейс та локалізація

- Нативний iOS інтерфейс (SwiftUI)
- Підтримка трьох мов: українська, англійська, естонська
- Перемикач мови в налаштуваннях
- Темна та світла теми (системні налаштування iOS)
- Підтримка deep links для прийняття запрошень

---

## Офлайн-режим та синхронізація

- Застосунок повністю працює без інтернет-з'єднання
- Локальна база даних — єдине джерело правди
- При наявності з'єднання: опціональна синхронізація даних між пристроями учасників ліги
- Вирішення конфліктів на основі версій записів (optimistic locking)
- Черга відкладених операцій для синхронізації при відновленні зв'язку
